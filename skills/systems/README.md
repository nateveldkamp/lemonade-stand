# Branch: Systems

*Making and maintaining the software side.*

At some point — usually around Stand stage 2 (family helps) or Stage 3 (multiple locations) — spreadsheets stop scaling. A small script does what a 200-row formula used to. A small program calls an API the spreadsheet can't. A small system runs every Sunday whether or not anyone remembers to open it.

This branch is where the audience builds the *software literacy* their grandkids will assume everyone had. Not "become a software engineer" — but enough to recognize when code is the right answer, write a small useful thing, and reason about whether it's still working.

## How this branch relates to the others

Systems is the *enabling layer* for the Automation branch — most Automation Skills are application-flavored, but they sit on Systems primitives. **Coding** specifically is the prerequisite for **Spreadsheet automation Tier 3+** (the report-generator moment), **Workflow automation Tier 2+**, and **Skill engineering**.

Systems also benefits from **Git** (Foundations) for any non-trivial work — version control is where coding lives.
