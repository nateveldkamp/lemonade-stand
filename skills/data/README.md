# Branch: Data

*Working with information — managing it, analyzing it, communicating it.*

Every business runs on data, even when the data is a few rows of numbers scribbled on a notepad at the end of the day. This branch covers the skills that turn raw information into something useful — first by organizing it, then by interrogating it, then by visualizing it for someone else.

These Skills start lightweight (a single spreadsheet's worth of weekend sales) and scale all the way to the data engineering needed by a multinational company. The audience meets each Skill at the smallest version of its problem.

## Skills in this branch

| Skill | Status | Tier-1 stand stage | What it covers |
|---|---|---|---|
| [Data management](data-management/) | **stub** | 1 — recurring weekend stand | Organizing data so it stays useful. Naming, storage, single source of truth, versioning. |
| [Data analysis](data-analysis/) | **stub** | 1 — recurring weekend stand | Making sense of data. Summarizing, comparing, finding patterns, drawing conclusions. |
| Data visualization | not started | 1–2 | Charts, graphs, communicating data visually. |
| Databases | not started | 2–3 | When data outgrows spreadsheets. SQL, structured data. |
| Data engineering | not started | 4+ | Pipelines, ETL, schema design at scale. |

## How this branch relates to the others

The Data branch sits one step above Foundations. Most Data Skills lean on **Spreadsheets** (Foundations) for early tiers and graduate to **Coding** (Systems) at higher tiers. Data analysis at Tier 3+ benefits from **Planning** (Operations) — analysis is only useful if it changes a decision.

The strongest cross-branch junction: **Data analysis** + **Spreadsheet automation** (in the Automation branch) is where the "factory not artifact" moment first lands for spreadsheet-fluent learners.
