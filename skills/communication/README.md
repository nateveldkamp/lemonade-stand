# Branch: Communication

*Telling the stand's story to people who matter.*

Knowledge work that nobody reads doesn't compound. This branch covers the Skills that turn what you've made — a forecast, an analysis, a system, a decision — into something other people can understand, act on, and build on.

Communication starts simple: a one-paragraph recap of the weekend, written for your sibling. It scales all the way to investor letters and board updates. The same underlying Skills show up at every level; what changes is the audience and the stakes.

## Skills in this branch

| Skill | Status | Tier-1 stand stage | What it covers |
|---|---|---|---|
| Writing | not started | 1 — recurring weekend stand | Clear, structured prose. The foundational Skill the rest of this branch depends on. |
| Storytelling | not started | 2 — family helps out | Narrative, persuasion, framing. Why the same facts land differently depending on how they're told. |
| Presentation | not started | 2–3 | Slides, decks, public-facing communication. |
| Stakeholder updates | not started | 3 — multiple locations | Recurring "here's where we are" messages. The discipline of repeated communication. |
| Documentation | not started | 2+ | Capturing knowledge for the next person. Different from writing for stakeholders — different audience, different rules. |

## How this branch relates to the others

Communication is the *output channel* for every other branch. Data analysis is wasted unless it gets communicated. Strategy doesn't move anything unless someone is convinced. Operations decisions don't get followed unless they're documented somewhere people can find them.

Two specific junctions worth flagging:

- **Data visualization** (Data branch) overlaps heavily with **Presentation**. A good chart is half presentation, half analysis.
- **Documentation** + **Skill engineering** (Automation branch) is the pair that determines whether anything you automate is reusable beyond yourself.
