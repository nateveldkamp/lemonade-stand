# Opening this folder in Cowork

You've unzipped the training folder. You see a directory called `lemonade-stand`. You're reading this file either as a PDF (probably `START_HERE.pdf` at the top of the folder) or — if you've already finished the steps below — inside Cowork itself.

If you're reading this *inside Cowork*, you've already done the work in this file. Skip to [README.md](README.md) and start the prelude.

If you're reading this as a PDF, keep going. The whole thing takes about five minutes.

## What you need

- A computer (Mac or Windows).
- A modern web browser (Safari, Chrome, Edge, or Firefox).
- An internet connection.
- The unzipped `lemonade-stand` folder visible somewhere on your machine — your Desktop is fine.

You do not need a terminal, a code editor, or any installed software. Those come later, only when a Skill you decide to learn (most likely Git, in the Foundations branch) calls for them — and the relevant drill walks you through every one.

## Step 1 — Open Cowork in your browser

Cowork lives at **claude.ai/cowork** *(URL to confirm at publication)*. Open it the same way you'd open any other site.

### On a Mac

1. Open Safari, Chrome, or Firefox.
2. In the address bar, type `claude.ai/cowork` and press Return.
3. If you're already signed in to Claude, you'll land in Cowork directly. If not, sign in or create a new account.

### On Windows

1. Open Edge, Chrome, or Firefox.
2. In the address bar, type `claude.ai/cowork` and press Enter.
3. If you're already signed in to Claude, you'll land in Cowork directly. If not, sign in or create a new account.

## Step 2 — Create a project

Once you're inside Cowork:

1. Click **New project** (the exact button label may vary slightly — look for a button that creates a new workspace).
2. Name it **Lemonade Stand**.
3. Confirm to create it.

You should now be looking at an empty Cowork project.

## Step 3 — Upload the lemonade-stand folder

Two ways to do this — either works.

### Option A — drag and drop

1. Open your file explorer (Finder on Mac, File Explorer on Windows) and find the unzipped `lemonade-stand` folder.
2. Drag the folder onto the Cowork project window. Drop it.
3. Cowork will start indexing the files. This usually takes well under a minute.

### Option B — click to upload

1. In Cowork, click **Upload files** (or **Add files** — exact label varies).
2. When the file picker opens, navigate to the unzipped `lemonade-stand` folder.
3. Select the entire folder and confirm.
4. Cowork will start indexing. Wait for it to finish.

## Step 4 — Verify you're in

When everything has uploaded, you should see:

- A file tree on the left of the window, with `lemonade-stand` (or whatever you named the project) at the top.
- Folders like `docs/`, `skills/`, `lemonade-stand/`, and files like `README.md` and `CLAUDE.md` underneath.
- Claude in a panel on the right of the window, ready to chat.

To confirm everything works:

1. In the file tree, click into `skills/`, then `prelude.welcome-to-the-stand/`.
2. Click on `README.md`.
3. The markdown should render in the main area — headings, paragraphs, links — much like you're reading this PDF, but inside the browser.
4. In the Claude panel on the right, type **Hi, can you see this folder?** and send it. Claude should respond confirming it can see the files.

If all four of those checks pass, you're in. You're done with this PDF. From here on, the course is read inside Cowork — switch to the `README.md` you just opened and start the prelude.

## Troubleshooting

**The page didn't load.** Try a different browser. If that doesn't work, check that you're online and that your organization's network doesn't block claude.ai.

**Sign-up isn't working.** If your organization already uses Claude, contact your IT team to get added. Otherwise, follow the standard sign-up flow on the Claude site.

**The folder didn't upload.** Try the other method (drag-and-drop instead of click-to-upload, or vice versa). If both fail, try uploading the contents of the folder rather than the folder itself.

**Claude doesn't seem to see my files.** Wait another moment — indexing can take up to a minute on a slow connection. Then ask something simple like "list the files in this project."

**Something else is wrong.** Make a note of exactly what happened — which step, what you saw, what you expected — and reach out through whatever channel your training program uses. We'd rather hear about the friction than have you stuck.
